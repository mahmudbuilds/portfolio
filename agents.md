# Project Instructions & Agent Rules

## Core Rules

1. **Package Manager: Bun**
   - **Always** use `bun` throughout this project for all package management, script execution, and development tasks.
   - Examples:
     - `bun install` / `bun add <package>` / `bun add -d <package>`
     - `bun run dev`
     - `bun run build`
     - `bun run lint`
   - Do NOT use npm, yarn, or pnpm.

2. **Framework & Stack**
   - **Next.js 16** (App Router)
   - **React 19**
   - **TypeScript**
   - **Tailwind CSS v4**
   - **Motion** (`motion` package, importing from `motion/react`)
   - **Lucide React** for modern sleek iconography

3. **Git Workflow**
   - Make atomic, descriptive git commits for each small milestone or component addition.
   - Push commits to the remote GitHub repository (`mahmudbuilds/portfolio`).
