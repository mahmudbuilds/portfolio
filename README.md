## ✨ Architectural Features

- ⚡ **React 19 + Vite 8:** Sub-millisecond HMR, zero hydration jank, and instant page transitions.
- 🎨 **Anti-Slop Taste-Skill 2.5 Design:**
  - Deep obsidian dark theme (`#07090e`, `#0c101a`) with subtle ambient telemetry.
  - Mona Sans display typography with tight tracking paired with Geist Mono.
  - No generic purple-on-dark, no keyword gradients, no empty bento fluff.
  - 60 FPS micro-animations: 2px card lifts, active button stepping, and tactile borders.
- 🧪 **Interactive Developer Workbench:**
  - **ResuMind ATS Simulator:** Interactive Applicant Tracking System AST evaluator with live 0-100 score gauges, keyword gap radar, and privacy-first client parsing.
  - **Inventry RBAC Inspector:** Multi-tenant claim inspector with live JWT decoded payloads, permission hierarchies (SuperAdmin, Manager, Auditor), and tenant isolation checks.
  - **Resonance Web Audio Visualizer:** Real-time 36-band FFT canvas frequency spectrum analyzer.
- ⌨️ **Interactive Developer Console / CLI (`⌘K` / `Ctrl+K`):**
  - Instant command runner (`help`, `projects`, `skills`, `cat resume`, `contact`, `hire`, `whoami`, `status`, `clear`).
  - Easter egg triggers with confetti celebrations.
- 📦 **Flagship Systems Deep-Dive:**
  - **Inventry:** Enterprise multi-tenant supply chain platform (Next.js 16 + Django REST + PostgreSQL on Neon). Live: [inventry-roan.vercel.app](https://inventry-roan.vercel.app).
  - **ResuMind:** AI-powered ATS resume analyzer & scoring engine with client-side multi-column PDF extraction (`pdfjs-dist`).
  - **Vesper:** High-fidelity 60 FPS interview copilot concept (React 19, Motion, Vite).
  - **Resonance:** Modern audio streaming & podcast discovery application.
  - **Full-Stack E-Commerce Platform:** Persistent PostgreSQL storefront with cloud database. Live: [ecommerce-project-tau-gray.vercel.app](https://ecommerce-project-tau-gray.vercel.app).
  - **Code Auditor Backend:** Python/Django AST static analysis and automated vulnerability detection.
- 📄 **Print-Ready Executive CV & Markdown Export:**
  - One-click print-to-PDF formatting (`@media print` clean paper styling).
  - One-click Markdown copy for ATS submissions.
- 📱 **100% Mobile & Edge Responsive:**
  - Tested across 390px, 768px, 1024px, and 1440px viewports with tactile touch targets.

## 🛠️ Tech Stack

- **Client & Runtime:** React 19, TypeScript (Strict mode)
- **Bundler:** Vite 8
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`) + Taste-Skill Design Tokens
- **Icons:** Lucide React & Custom Brand Vectors
- **Interactive Effects:** Canvas Confetti, Web Audio API, Canvas 2D Context
- **Deployment:** Vercel Global Edge Network

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/mahmudbuilds/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
