## Architecture & Features

- **Editorial Light & Dark System:** Warm paper (`#faf9f6`) and deep obsidian (`#111110`) palettes paired with Newsreader, DM Sans, and JetBrains Mono.
- **Visual Proof & Diagrams:** Media-led flagship showcase featuring live screenshots, an interactive Resonance-inspired hero waveform, and a custom SVG PostgreSQL row-locking concurrency diagram.
- **Downloadable ATS Resume:** Direct static PDF download (`public/Mahmud-Tella-Resume.pdf`) alongside an accessible in-browser resume modal with Markdown copy and print formatting.
- **Sticky Navigation & Accessibility:** Active-section tracking, skip-to-content link, proper semantic landmarks, focus-trapped modal, and WCAG AA contrast.

## Local Development

```bash
# Clone the repository
git clone https://github.com/mahmudbuilds/portfolio.git
cd portfolio

# Install dependencies
bun install

# Start development server
bun run dev

# Build for production
bun run build
```
