## ✨ Design & Architecture

- **Minimalist Editorial Layout:** Single-column reading flow (`max-w-2xl`), deep obsidian dark palette (`#09090b`), restrained typography, and subtle hairline borders. Zero template slop.
- **Mobile-First Responsiveness:** Fully fluid on narrow mobile viewports (360px–420px), responsive availability status pill, touch-friendly 2x2 action buttons, and horizontal-scrolling category filters.
- **Printable Executive Resume:** In-browser document modal with one-click **Print / Save as PDF** and **Copy Markdown** formatting.
- **Speed & Efficiency:** Instant page load, zero layout shift, sub-second production build (~350ms) powered by React 19 and Vite 8.

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/mahmudbuilds/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
